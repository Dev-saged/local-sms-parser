## 🇸🇦 قسم اللغة العربية

### 📝 نبذة عن المشروع
**Local SMS Parser** عبارة عن سكربت ذكي وتطبيق ويب يعمل بالكامل من جهة العميل (Client-Side) مخصص لمعالجة ملفات Excel وقوائم الأرقام. يقوم النظام بتنظيف مفاتيح الاتصال الدولية ومعالجة البيانات لتوليد رسائل SMS نصية مخصصة للعملاء والمستفيدين بشكل آلي.

### 🌟 المميزات الرئيسية
*   📱 **تركيز حصري على SMS:** مصمم خصيصاً لعمليات الـ SMS المحلية، مع استبعاد مقصود لبرمجيات واجهات WhatsApp للحفاظ على أداة خفيفة، مباشرة، وتؤدي غرضها بدقة.
*   🧹 **تنظيف البيانات (Data Cleaning):** معالجة ذكية للأرقام وإزالة أو تعديل مفاتيح الاتصال الدولية لتلائم الشبكات المحلية.
*   🔒 **معالجة محلية 100%:** قراءة وتحليل ملفات الإكسل تتم داخل متصفح المستخدم دون رفع أي بيانات حساسة لأي سيرفر خارجي.
*   ⚡ **أتمتة النصوص:** توليد صفوف من الرسائل الجاهزة للإرسال فوراً بناءً على قوالب مخصصة.

## 🇺🇸 English Section

### 📝 Project Overview
**Local SMS Parser** is a pure client-side web utility designed to parse Excel sheets, clean international dialing prefixes, and systematically generate formatted text notifications. It provides a seamless, browser-based environment to automate localized outreach campaigns without compromising data privacy.

### 🌟 Key Features
*   📱 **Strictly SMS-Targeted:** Engineered specifically for SMS operations, intentionally bypassing WhatsApp parameters to maintain a highly focused, lightweight dispatch tool.
*   🧹 **Intelligent Data Cleaning:** Automatically formats and standardizes phone numbers and dialing codes from raw spreadsheet data.
*   🔒 **Zero-Server Processing:** Excel parsing and data extraction happen entirely within the DOM. No external server dependencies, ensuring absolute privacy.
*   ⚡ **Automated Message Generation:** Instantly compiles targeted message rows ready for batch sending.
